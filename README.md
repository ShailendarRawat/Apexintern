# ApexPlanet Web Development Internship — Portfolio

Single-page portfolio with Tasks 1–3 (HTML, CSS, JavaScript).

## Weather API setup (required for local use)

The OpenWeatherMap API key is **not** stored in the repo.

```bash
cp config.example.js config.js
```

Then open `config.js` and replace `YOUR_API_KEY_HERE` with your key from [openweathermap.org/api](https://openweathermap.org/api).

`config.js` is listed in `.gitignore` and will not be pushed to GitHub.
